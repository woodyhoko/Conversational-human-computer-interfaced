A conversational email agent that chains speech recognition → intent classification → named entity recognition → dialogue management → Gmail execution. It figures out what you want to do, who with, and what to say — then confirms before sending.

The paper is a research proposal (originally in Traditional Chinese; an English version is provided). The demo below is a simplified illustration of the proposed pipeline, not the full system.

architecture
A five-stage NLP pipeline.
01

Speech recognition

Google / Bing / Kaldi / DeepSpeech back-ends

→ transcript
02

Intent classification

Hybrid dictionary + ML over 5 intents

→ {READ, SEND, PICK…}
03

Named entity recognition

Bi-LSTM + CRF — 83.7 F1 on the dev set

→ {recipient, content…}
04

Dialogue manager

Slot-filling FSM with clarification + confirm

→ action spec
05

Gmail executor

list / read / send / forward — never without confirm

→ TTS reply
example
A real exchange.
